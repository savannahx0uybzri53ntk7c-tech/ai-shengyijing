# Repository maintenance

Scope: four public Skills and their synthetic examples. Select the matching `SKILL.md`;
do not load or rewrite every Skill for an unrelated request.

Preserve trigger boundaries, source attribution, user-approved prose, output contracts and stopping criteria.
Do not reconnect private corpora, account configuration, schedules or publishing integrations.
Never commit private conversations, customer records, credentials or actual operating data.

Use synthetic input for checks. For diagram changes, validate the fixture, compile a new output and
test the specific failure. Inspect real phone and desktop screenshots when changing page appearance.
Contract checks and model-written demonstrations are not independent quality certification or business results.

Human review remains required for releases, licensing changes and public commitments unless the user
has explicitly authorized that exact action. Report what actually ran and which modes remain unverified.
