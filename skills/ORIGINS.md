# 来源与公开改编范围

首批四个 Skills 是 AI生意经自用工作流的独立公开改编，重新定义了面向外部用户的输入、运行依赖与交付边界。它们不替代私人版本，也不宣称包含私人版本的全部业务能力。

| 公开 Skill | 自用能力来源 | 保留的核心 |
| --- | --- | --- |
| topic-selection | 内容中台选题 | 四种模式、已有材料优先、母问题×变量、来源驱动拆题、证据分层 |
| article-writing | 公众号写稿与正文执行 | 任务原型、读者问题链、分段再组装、局部修订保护、创作与事实分层 |
| moments-writing | 写朋友圈及朋友圈轻运行核心 | 本人原话、一个主念头、自然收口、生活与商业分流、图文完成状态 |
| html-story | HTML生产总控、图示与审美工法 | 阅读/演示/双模式、内容保真、原文与总结分流、移动端重排、真实视觉验收 |

公开版将作者身份、私有资料库、商业计划、报价、客户事实、真人照片、品牌资产、账号标识、定时任务与发布连接改为使用者提供或明确接入。没有带出私人原文、客户故事、内部聊天或付费原文库。默认不包含跨聊天调度或无人值守运营能力。

## 方法借鉴

这些工作流长期吸收了公开写作、编辑、设计与知识管理方法，不能将所有思想宣称为独创。公开文档按上述任务重新组织，不分发第三方完整 Skill、独特样稿、提示词模板或人物语料库。

自用长文工法记录了卡兹克写作方法等外部学习来源；本公开版保留读者问题链与编辑动作，不携带其上游 Skill、文风模板或运行依赖，也不表示作者背书或授权。

随 `html-story` 分发的 `scripts/diagram_compiler.py` 来自本项目维护者的自用 HTML Agent 适配器，独立编写，公开候选保留源码。其原始设计记录了以下方法参考：

- [fireworks-tech-graph](https://github.com/yizhiyanhua-ai/fireworks-tech-graph)：语义输入、节点与边校验、箭头语义、可访问 SVG。
- [diagram-design](https://github.com/cathrynlavery/diagram-design)：画布、受众、密度、手机重排与忠实度检查。
- [taste-skill](https://github.com/Leonxlnx/taste-skill)：设计判断、密度/变化/动效调节、反模板与交付回看。

这些链接是方法来源说明；包内没有复制上游主题库、组件、示例图、字体、图标或运行时。没有将方法来源声明当作上游全部内容的再分发许可。新增第三方代码或资产时，先核对对应版本、授权范围并保留必需许可。
