# HTML讲述页

AI生意经公开版：交真实可打开的 HTML，而不是代码片段或预览截图。三个入口：阅读页、演示页、阅读与演示双模式。起手句：`把这份内容做成手机能读的独立HTML，保留事实与限制，关系用图说明。`
任务明确直接做；缺关键原稿只问原稿，不要求用户重新解释已定风格。

## 输入与事实

锁定内容、受众、用途、输出位置与授权素材。已有文件和审美优先；修改时保留原文件与认可部分，只改本轮要求。

普通“做成 HTML”保留实质结论、数据、案例、限制和动作，允许重排，未经授权不自动摘要。只有明确要求“播客总结／抓重点”才提炼；使用用户提供或授权取得的真实逐字稿，不以标题、简介、智能摘要冒充全文。原稿缺页则说明范围。

总结先定核心判断，再组织关键观点、故事、方法与限制；原文另存，不隐藏塞回整页。真实金句逐句核对说话人和时间位置，缺时间不编造；未核原音频注明转写边界。总结任务不自动扩成账号选题与全频道采集。

## 页面与视觉

- 长文、手册、研究阅读用 `article`，以稳定版心和连续正文为主。
- 视觉叙事长页用 `scroll`，先排 390×844，再扩到 1440×900。
- 明确投屏、录课、翻页用 `deck`，1920×1080 舞台整体缩放。
- 明确要求双模式用独立阅读 DOM 与 deck DOM，以真实按钮切换；共享同一事实，不将 deck 固定尺寸覆盖阅读页。

风格继承用户参考。没有指定时按内容选一种：商业的暖黑与克制金色、行动成长的清晰高对比、人文研究的暖纸与衬线标题。它们是可选表达，不是需要用户重新选择的菜单。封面主标题、副标题与一句判断各有任务，品牌可由用户提供，默认无私人 Logo、人物或宣传口号。

先在当前任务状态明确页面要让人看懂什么、信息密度与动效强度，再写 DOM。一个强调色承担明确含义，构图服从内容，避免整页等大卡片。文章可以连续阅读，不为构图数量制造假图。演示页使用判断、解释、证据、对照、时间、图示与留白等不同布局，不把每页做成一样的三栏。

真实人物、产品、界面和数据用授权真实资产；没有就保留留白或有信息的结构图，不画相似 Logo、陌生脸、假报表或假截图填位。真实数据保留单位、口径、基准与日期；不同量纲不放同一数轴。动效有用途、可停止，并支持 `prefers-reduced-motion`。

## 语义图示

内容确有流程、层级、关系、循环、时间、矩阵或对照时才画。先说明关系，再定图形；箭头表示实际关系，无证据不连。复杂图先分组和主路径，超过九节点优先总览＋细节；手机重排，不靠缩小标签或横向滑动承载核心理解。

可用 Python 时读取 [图示合同](references/diagram-contract.md)，用随包的原生脚本：

```sh
python3 scripts/diagram_compiler.py examples/flow.json --style humanist --form scroll --output diagram.html
```

路径相对此 Skill 目录。脚本生成 HTML 片段，要内联进最终文件；按合同添加桌面与手机图形显隐样式。实际运行后才能声称使用了编译器。不可执行脚本时可手写内联 SVG，遵守同一关系、保真与可访问性检查，明确脚本未运行。

## 文件实现

生成 UTF-8 自包含 HTML，CSS/JS 内联；不用 CDN、远程字体、第三方运行时或维护者本地文件。授权图片用内联数据或经用户确认的交付附件；自包含交付默认内联。新增脚本只为必要交互，不收集输入或自动发送数据。

标题和章节形成可导航层级。长标题按中文语义换行；图形文字不被线穿过，颜色与字号在手机可读；SVG 有 title/desc。真实交互支持键盘与焦点，纯展示不放假按钮。双模式切换保留事实与必要限制，逐一核两端。

## 验证与交付

先确认文件存在、正文与引用保真、自包含、无残留私有路径，必要交互实际可用。用当前授权的真实浏览器打开文件，检查 390×844 和 1440×900 的封面、最复杂图形、正文与结尾，发现溢出、孤字、裁切和遮挡就修复。

遵守当前运行环境的浏览器规则，只有实际可用工具才报告已执行。未看截图标“视觉待回看”，浏览器受限标“视觉回看受限”；源码和 DOM 检查不冒充视觉验收。没有相应授权不启动服务、安装浏览器或启用网络。

返回最终真实路径、风格、页面形态、可见变化、静态检查与两端截图状态、待作者审阅项。修改原稿默认原位更新用户选定对象，保存失败不报成功。只要 HTML 就在 HTML 停止，不自动 PDF、部署或公开发布。
