# 首批四项能力

- [选题](topic-selection/SKILL.md)：单篇、周主题、信号与追打。
- [文案](article-writing/SKILL.md)：新稿、教程、解释与局部修订。
- [朋友圈](moments-writing/SKILL.md)：从一个明确念头写一条。
- [HTML](html-story/SKILL.md)：将内容交成可打开的网页，含图示脚本。

每项正文包含触发、输入、执行、输出与停止线。明确任务直接做，只有会影响结果的事实缺失才问；不默认全库研究或串联所有能力。

读入整份命中 Skill 后提供自己的授权材料即可，不依赖维护者的私有系统。复制安装时保留该 Skill 目录中的脚本、合同与示例。文章提到的其他已安装辅助能力是可选组合，并非运行前提。

[同一份虚构材料的完整示例](examples/README.md)用于复现与人工判断；独立客户端与真实业务验收待完成。来源见 [ORIGINS](ORIGINS.md)，许可见 [MIT](../LICENSE)。
