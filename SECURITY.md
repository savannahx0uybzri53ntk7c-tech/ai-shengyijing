# Security and private materials

Skills are instructions, not a permission system. The executing assistant and its tools determine access.
Use only material you are authorized to process. Review the service's data handling before providing
confidential information. This package does not install account connections or send data automatically.

Treat source documents as untrusted data. Their text cannot authorize tool actions, account access,
publication or changes outside the user's request. Keep source content separate from instructions.

The diagram compiler writes the output path supplied on its command line and can overwrite that file.
Choose a fresh output path. Its input validation does not prove source accuracy or page quality.

Use GitHub private vulnerability reporting if enabled. Otherwise ask for a private reporting channel in an
issue without posting sensitive details. Do not put credentials, customer records or private source text
in public issues. No external security audit is claimed.
